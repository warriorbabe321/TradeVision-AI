# Personal US Stock Analysis Tool

A customizable tool for US stock market analysis and decision making.

## Project Structure

- `src/data_fetcher`: Modules for retrieving data from various financial APIs.
- `src/indicators`: Technical and fundamental indicator calculations.
- `src/analysis`: Strategy and analysis logic.
- `src/utils`: Utility functions and configuration management.
- `data`: Local data storage and caching.

## Setup

1. Install dependencies: `pip install -r requirements.txt`
2. Configure API keys in `.env` (if applicable).
3. Run the main script: `python main.py`
